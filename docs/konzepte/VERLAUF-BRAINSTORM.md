# Brainstorming: Neuartige Verlaufsdarstellung

**Stand:** 15.11.2026 · **Modus:** hohe Temperatur, Chaos erlaubt – aber jede Idee muss eine Ordnung haben.

**Gesetzt (vom Product Owner gewählt):** Chat-Ansicht · Zeitstrahl pro Kontakt · Zusammenfassung zuerst · Themen-Gruppierung
**Random Seeds (Product Owner):** Schnüre der Chaski (Quipu) · horizontal statt vertikal · Tinder-Swipe · Hexagramm · Blackboard/Whiteboard · Mindmap
**Random Seeds (zusätzlich):** U-Bahn-Netzplan · Musik-Partitur · Jahresringe · Sternbild · Comic-Strip · Kartenstapel · Fluss-Delta · Detektivwand

Jede Idee hat drei Teile: **Bild** (wie sieht es aus), **Ordnung** (warum es trotz Chaos übersichtlich bleibt), **Glänzt bei** (wofür es wirklich taugt).

## 1. Quipu – die Schnüre der Chaski

Die Inka hatten keine Schrift, aber das **Quipu**: eine Hauptschnur, an der farbige Schnüre mit Knoten hängen. Chaski-Läufer trugen damit Steuern, Volkszählungen und Nachrichten durchs Reich. Ein Buchhaltungssystem aus Knoten – passt verblüffend gut zu E-Mail.

```
Hauptschnur = Zeit  ───────────────────────────────────────────▶
   │            │             │               │
   ┊ Keller     ┊ SBB         ┊ Swisscom      ┊ Mama
   ● Anfrage    ⊛ Ticket      ═ Rechnung 79.– ● "Sonntag?"
   ● Offerte    ┊             ═ Rechnung 79.– ● "Ja, 12h"
   ● Zusage     ┊             ═ Rechnung 82.– ┊
   ═ Rechnung   ┊             ┊               ┊
```

- **Knotenarten:** einfacher Knoten ● = Mail · langer Knoten ═ = Rechnung · Achterknoten ⊛ = Ticket · loser Faden = unbeantwortet.
- **Farbe der Schnur** = Kategorie; **Dicke** = Beziehungsintensität.
- **An einer Schnur ziehen** = Verlauf aufklappen (wird zur Chat-Ansicht).
- **Ordnung:** Das Quipu war ein Zählsystem → Rechnungen pro Rechnungssteller sind buchstäblich „Knoten zählen“; Summen pro Schnur stehen am Ende.
- **Glänzt bei:** Rechnungsablage, Überblick „wer schreibt mir wie oft“, Querformat.

## 2. Horizontal statt vertikal – die Partitur

Der Verlauf läuft **von links nach rechts wie eine Musikpartitur**. Jede beteiligte Person hat ihre eigene Notenzeile.

```
          3.11.     5.11.        6.11.       12.11.    20.11.
Ich     ──●───────────────────────●──────────────────────────
Keller  ────────────●📎─────────────────────────═────────📅──
Buchh.  ─────────────────────────────────────────═───────────
```

- **Antwort an alle** = Akkord (mehrere Zeilen gleichzeitig).
- **Pausen** sichtbar: lange Stille = Leerraum → „Du wartest seit 9 Tagen“.
- **Handy hochkant = Chat, Handy quer = Partitur.** Drehen ist die Geste zum Perspektivwechsel.
- **Ordnung:** Zeit hat eine Richtung, Personen haben eine Zeile – zwei Achsen, null Zitat-Ketten.
- **Glänzt bei:** Gruppen-Threads, „wer ist dran?“, Verhandlungen.

## 3. Tinder-Swipe – Verlauf als Kartenstapel

Jeder Vorgang ist eine Karte. Swipen ist Triage **und** Geschichte.

```
      ┌─────────────────────────┐
      │ 🏠 Küche neu             │
      │ Montage 20.11.          │      ← später    erledigt →
      │ Rechnung CHF 4'200 offen│      ↑ Pole Position
      │ Du bist dran            │      ↓ weg damit
      └─────────────────────────┘
```

- **Horizontal tippen** (wie Instagram-Stories) = durch die Geschichte des Vorgangs blättern, Nachricht für Nachricht, jede als Vollbild-Karte mit Kernsatz.
- **Swipen** = entscheiden.
- **Ordnung:** immer genau **eine** Sache im Blick. Chaos wird zur Warteschlange.
- **Glänzt bei:** morgendliches Abarbeiten in 2 Minuten, Daumen-Bedienung.

## 4. Hexagramm – der Status-Glyph

Inspiriert vom I Ging: sechs Linien, durchgezogen oder gebrochen, ergeben 64 Zeichen. Jeder Vorgang bekommt ein **eigenes Hexagramm**, das seinen Zustand auf einen Blick zeigt.

```
 ━━━━━━  verschlüsselt?     ━━━━━━ = ja
 ━━  ━━  Termin?            ━━  ━━ = nein
 ━━━━━━  Geld im Spiel?
 ━━━━━━  offen?
 ━━  ━━  Anhang?
 ━━━━━━  du bist dran?
```

- Nach einer Woche liest man die Glyphen wie Verkehrszeichen: „drei durchgezogene oben = offene Rechnung, ich muss handeln“.
- **Ordnung:** Sechs feste Fragen, immer gleiche Reihenfolge. Maximal kompakt – passt neben jede Zeile, in Widgets, auf die Watch.
- **Glänzt bei:** Listen, Widgets, Apple Watch / Wear OS.

## 5. Hexagon-Wabe – Themenlandkarte

Jedes Thema ist eine Wabe. Benachbarte Waben teilen Personen.

```
        ⬡ Ferien      ⬡ Auto
     ⬡ Küche  ⬢ Familie  ⬡ Steuern
        ⬡ Keller-Rg.  ⬡ Hund
```

- **Grösse** = Aktivität, **Farbe** = Zustand (rot = du bist dran, grau = ruht, grün = erledigt).
- Die Wabe **wächst organisch** – neue Themen docken dort an, wo sie Personen teilen.
- **Ordnung:** Bienenwaben sind die effizienteste Flächenaufteilung – kein Platz verschwendet, jede Wabe hat genau sechs Nachbarn.
- **Glänzt bei:** Themen-Gruppierung, „was läuft gerade in meinem Leben?“

## 6. Blackboard / Detektivwand

Eine Pinnwand mit Notizzetteln, Fotos der Anhänge und **roten Fäden** zwischen allem, was zusammengehört.

```
 ┌─────────────────────────────────────────────┐
 │  [Offerte.pdf]───────[Zusage 6.11.]          │
 │       │   ╲                │                 │
 │  [M. Keller]  ╲────[Rechnung 4'200]           │
 │       │              │                       │
 │  [Termin 20.11.]────[Buchhaltung Keller]     │
 └─────────────────────────────────────────────┘
```

- KI pinnt automatisch; Nutzer kann Zettel verschieben, Fäden ziehen, mit Kreide Notizen daneben schreiben.
- **Ordnung:** Fäden zeigen nur echte Bezüge (gleiche Rechnungsnummer, Antwort-auf, gleiche Person, gleicher Termin).
- **Glänzt bei:** komplexe Vorgänge (Hausbau, Versicherungsfall, Streit mit Vermieter), iPad/Tablet.

## 7. Mindmap

Thema in der Mitte, Äste zu Personen und Unterthemen, Blätter sind Nachrichten.

```
                 ┌ Offerte ─ Offerte_123.pdf
     Keller ─────┤
    ╱            └ Rechnung ─ CHF 4'200 (offen)
 Küche
    ╲            ┌ Lieferung 18.11.
     Elektro ────┤
                 └ Anschluss Herd
```

- **Ordnung:** Radial = keine Zeitachse nötig; sortiert nach Bedeutung, nicht nach Datum.
- **Glänzt bei:** Projekte mit vielen Beteiligten, Planung.

## 8. U-Bahn-Netzplan

Jede Person ist eine **Linie**, jedes Thema eine **Station**. Wo Linien sich kreuzen, waren mehrere Personen beteiligt.

```
 Keller ━━━●━━━━━●━━━━━━●━━━━▶
                 ┃      ┃
 Elektro ━━━━━━━━●━━━━━━╋━━━━▶
                        ┃
 Buchhaltung ━━━━━━━━━━━●━━━━▶
           Offerte  Termin  Rechnung
```

- „Mit der Keller-Linie fahren“ = chronologischer Verlauf mit einer Person.
- **Ordnung:** Netzpläne sind seit 1933 das Paradebeispiel, wie man Chaos lesbar macht – nur Topologie, keine Massstabstreue.
- **Glänzt bei:** Zeitstrahl pro Kontakt + Themen gleichzeitig.

## 9. Jahresringe

Im Kopf jeder Kontaktseite: ein Baumquerschnitt. Innen = alt, aussen = jetzt. Ringdicke = wie viel ihr euch geschrieben habt.

```
      ╭───────╮
    ╭─┤ ╭───╮ ├─╮     2026 dick (Küchenprojekt)
    │ │ │ ● │ │ │     2025 dünn
    ╰─┤ ╰───╯ ├─╯     2023 erster Kontakt
      ╰───────╯
```

- **Ordnung:** sofort lesbar, wie alt und wie intensiv eine Beziehung ist.
- **Glänzt bei:** Kontaktseite, „seit wann kenne ich die?“

## 10. Sternbild

Kontakte sind Sterne. Helligkeit = Wichtigkeit, Nähe = wie oft sie gemeinsam in Mails vorkommen. Themen bilden Sternbilder.

- **Ordnung:** Das Auge findet Muster von selbst; die KI zeichnet die Linien der Sternbilder.
- **Glänzt bei:** Netzwerk-Überblick, „wer gehört zu wem?“ – eher Entdeckungsmodus als Alltag.

## 11. Comic-Strip

Ein langer Thread wird zu drei bis sechs Panels. Die KI schreibt Erzähltexte dazwischen („Zwei Wochen später, bei der Schreinerei …“).

- **Ordnung:** Comics komprimieren Zeit radikal; Leerstellen zwischen den Panels sind gewollt.
- **Glänzt bei:** Zusammenfassungen langer Threads, Teilen eines Verlaufs mit jemandem, der nicht dabei war.

## 12. Fluss-Delta

Ein Thread, der sich durch „Antwort an einzelne“ aufspaltet, wird zum Delta: Nebenarme zweigen ab, fliessen wieder zusammen.

- **Ordnung:** zeigt, wo eine Diskussion auseinanderlief – und wo nicht mehr alle informiert sind („Seitenarm ohne Buchhaltung“).
- **Glänzt bei:** Firmen-Mails, Reply-All-Chaos.

## Synthese: „Chaos mit Zoomstufen“

Die Ordnung entsteht durch **semantischen Zoom**: Mit zwei Fingern rein- und rauszoomen wechselt nicht nur die Grösse, sondern die **Darstellungsform**. Jede Stufe ist für sich ruhig und klar – das Chaos liegt nur im Wechsel dazwischen.

```
  Zoom ganz raus        Zoom mittel                    Zoom ganz rein
 ┌──────────────┐     ┌────────────────────────┐     ┌──────────────────┐
 │ ⬡ ⬢ ⬡        │     │ Zusammenfassung-Karte  │     │ ┌Zusammenfassung┐ │
 │  ⬡ ⬡ ⬢       │ ──▶ │ ───●────●───═────📅──▶ │ ──▶ │ └───────────────┘ │
 │ Themen-Wabe  │     │ Quipu / Partitur       │     │  Chat-Blasen     │
 └──────────────┘     └────────────────────────┘     └──────────────────┘
    Themen-             Zeitstrahl pro                  Chat-Ansicht
    Gruppierung         Kontakt/Thema                   + Zusammenfassung zuerst
```

| Element | Wird zu | Aus Idee |
|---|---|---|
| Themen-Gruppierung | **Wabe** als oberste Zoomstufe | 5 |
| Zeitstrahl pro Kontakt | **Quipu-Schnüre**, im Querformat als **Partitur** | 1, 2 |
| Zusammenfassung zuerst | **Kopfkarte** jedes Vorgangs: Worum, Stand, offen, wer ist dran | – |
| Chat-Ansicht | unterste Zoomstufe, Zitate entfernt | – |
| Status überall | **Hexagramm-Glyph** neben jedem Vorgang, in Widgets, auf der Watch | 4 |
| Tägliche Triage | **Swipe-Stapel** auf der Pole Position, Tippen = Stories durch den Verlauf | 3 |
| Kontaktseite | **Jahresringe** im Kopf, darunter die Quipu-Schnur | 9 |
| Power-Modus | **Blackboard** für komplexe Vorgänge (v. a. Tablet) | 6 |

**Handy drehen** ist die zweite Achse: hochkant = lesen und antworten (Chat), quer = überblicken (Partitur/Quipu).

**Für später / Experimente:** U-Bahn-Netzplan, Comic-Strip-Zusammenfassung zum Teilen, Fluss-Delta für Firmenkonten, Sternbild als Easter Egg.
